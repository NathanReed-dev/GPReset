# GP-RESET

A Minecraft Reset Plugin that Respects player claims provided by [Grief Prevention](https://modrinth.com/plugin/griefprevention).

# Plan

![plan](Images/plan.png)


## Permissions

```gpreset.admin```

## How to Use:-

```
/gpreset help
/gpreset preview
/gpreset <world name>
/gpreset reload

```
